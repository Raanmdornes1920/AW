Bocetos del sistema BISTRO FDI

Pantalla 1: Página Principal

Funcionalidad: acceso general al sistema y visualización destacada de productos/menús.

Elementos principales

  • Cabecera con logo y menú de navegación
  • Zona destacada con menú del día o productos populares
  • Botón para explorar la carta completa

Navegación

  • Botón "Ver carta" → Pantalla de listado
  • Botón "Iniciar sesión" → Pantalla de login

Pantalla 2: Carta / Listado de productos

Funcionalidad: exploración y filtrado de platos disponibles.

Elementos principales

  • Buscador por nombre
  • Filtros por tipo o alérgenos
  • Tarjetas con imagen, nombre y precio

Navegación

  • Click en un producto → Pantalla de detalle
  • Volver → Página principal

Pantalla 3: Detalle de producto

Funcionalidad: visualización completa de información del plato.

Elementos principales

  • Imagen del plato
  • Descripción completa
  • Información de alérgenos
  • Botón para realizar pedido o acción principal

Navegación

  • Botón "Pedir" → Confirmación / Login si no está autenticado
  • Volver → Listado

Pantalla 4: Login / Registro

Funcionalidad: autenticación del usuario para realizar pedidos o guardar favoritos.

Navegación

  • Enviar formulario → Perfil del usuario
  • Enlace "Crear cuenta" → Registro

Recorridos principales del sistema

Recorrido A: Usuario realiza un pedido

  1. Accede a la página principal
  2. Explora la carta
  3. Selecciona un producto
  4. Pulsa "Pedir"
  5. Inicia sesión si es necesario
  6. Confirma la acción

Recorrido B: Usuario consulta información de alérgenos

  1. Accede a la carta
  2. Aplica filtro por alérgenos
  3. Consulta detalle del producto
